# Эмулятор оболочки ОС (Вариант 6)

## Общее описание
Учебный проект по дисциплине «Конфигурационное управление».
Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом.

## Функциональность (Этап 1)
- Графический интерфейс (GUI) на базе Tkinter.
- Приглашение к вводу и заголовок окна на основе имени VFS.
- Парсер команд с поддержкой аргументов в кавычках.
- Обработка ошибок (неизвестная команда, неверные аргументы).
- Заглушки команд: `ls`, `cd`.
- Команда `exit` для выхода.

## Описание команд
- `ls [аргументы]` — выводит имя команды и переданные аргументы.
- `cd [аргументы]` — выводит имя команды и переданные аргументы.
- `exit` — закрывает приложение.
