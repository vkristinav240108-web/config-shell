# Эмулятор оболочки ОС (Вариант 6)

## Общее описание
Учебный проект по дисциплине «Конфигурационное управление».
Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом (GUI).

## Описание всех функций и настроек
- **Графический интерфейс:** окно с областью ввода и областью истории.
- **Заголовок окна:** отображает имя виртуальной файловой системы (VFS).
- **Параметры командной строки:**
  - `--vfs <путь>` — путь к JSON-файлу виртуальной файловой системы.
  - `--script <путь>` — путь к стартовому скрипту, который выполняется при запуске.
- **Команды:**
  - `ls` — вывести содержимое текущей директории.
  - `cd <путь>` — перейти в другую директорию.
  - `wc <файл>` — вывести количество строк, слов и символов в файле.
  - `uniq <файл>` — вывести уникальные строки из файла.
  - `rmdir <путь>` — удалить пустую директорию.
  - `vfs-init` — сбросить текущую VFS к состоянию по умолчанию.
  - `exit` — закрыть эмулятор.
- **Стартовый скрипт:** выполняется последовательно, останавливается при первой ошибке. Ввод и вывод отображаются в окне.
